# models/weapons

`wolfstrike_m4a1.glb` - the supplied, optimized M4A1 model (primary rifle), used unmodified.
Placement, sights, muzzle and hand points: `src/config/weaponModels.ts` (measured on this mesh).
Its Market / Envanter card image `assets/ui/weapons/m4a1.png` is a render of this GLB.

Optional: `pistol.glb` (first-person view model; optional `muzzle` node) - see ../README.md.
